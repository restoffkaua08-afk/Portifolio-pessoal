# `> PROJECT.OVERVIEW`

Este repositório contém o portfólio pessoal de **Kauã Restoff**, desenvolvido para reunir apresentação profissional, conhecimentos técnicos, projetos, currículo e meios de contato em uma experiência única.

A aplicação foi implementada sem framework e concentra estrutura, estilos e comportamento em um documento HTML. Essa abordagem mantém a publicação simples e demonstra domínio de fundamentos web, embora a separação futura dos arquivos possa facilitar manutenção e evolução.

<br>

# `> GETTING.STARTED`

```bash
git clone https://github.com/restoffkaua08-afk/Portifolio-pessoal.git
cd Portifolio-pessoal
```

Abra `index.html` diretamente no navegador ou utilize um servidor estático local.

```bash
npx serve .
```

# `> QUALITY.ASSURANCE`

Antes de publicar, valide:

- navegação e links;
- alternância de temas;
- menu móvel;
- responsividade;
- carregamento do currículo;
- conteúdo em todos os idiomas disponíveis;
- ausência de erros no console do navegador.
